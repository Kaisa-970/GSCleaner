数据包含 120 个带物体视角、10 个清场视角，清场图与 unseen_mask 名称完全匹配。

原标签已备份，以最近邻对齐尺寸后，关联和蒸馏完成；尺寸修正记录在远端
`output/mvp-toys-20261013/mask_alignment.json`。
