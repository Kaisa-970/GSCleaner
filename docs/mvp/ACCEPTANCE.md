## 执行偏离与结论边界

- Run 1 与 Run 2 比较验证的是整条修复流程的总效果，不能分离 LaMa、融合新增几何、增密和优化各自的贡献。尚无等步数的无生成补全优化对照，不能将改善主要归因于 inpainting。
- 实际代码以 finetune_iteration=5000 从零执行独立修复循环；iteration_2000 是对象感知 checkpoint 标号，iteration_5000 是修复循环输出标号，不能相减得出“额外 3000 步”。优化使用虚拟视角伪监督，并在保存前恢复原保留 Gaussian，再选择性写回投影区域内参数；不是简单连续训练原场景到第 5000 步。
- 用户批准 A 通过后改用 toys 验证多目标，没有在 bag 中凑多个目标。这是另一场景的多目标验证，不是同场景增加目标数量的消融。
- toys 默认 min_area=50 会丢失有效小标注，改为非零标签并集、min_area=0，保留 10 像素扩张。这是有记录的预处理偏离。LaMa、融合和优化损失未修改，结果不称为未经修改的官方默认复现。
- 使用严格区域 MSE/PSNR 判断改善，没有交付官方置零 masked/FID 指标或论文 Table 1 复现，两种指标口径不可直接对比。
- 历史完整链路资源峰值未记录。独立复跑补充资源可行性证据，0.5 秒采样可能遗漏短暂尖峰，不是历史或严格瞬时峰值，也不是全链路重训练。
- toys 非修复区 PSNR 汇总下降 0.282 dB（9/10 视角下降），并有局部模糊和纹理误差。用户验收通过仍不等于背景完全不变。
- 投影支持区域不是人工语义 GT，官方 unseen_mask 的上游标注来源未独立证明；文件对应、极性和可见区域已核验，不宣称完成语义零误删证明。
- 基础训练较短、分辨率因子为 8。结果支持继续研发，不证明仓储场景泛化、高保真资产交付或完整产品已经完成。

## 停止原因与下一步

单目标和多目标删除修复均已有定量改善与用户动态验收证据，继续优化纹理不属于本轮目标。因此停止本轮开发，保留上述例外，不将原计划每项条款都标为无条件完成。

下一轮优先定义无生成补全、等优化预算的对照，分离额外优化与生成修复的贡献。必须明确可用背景监督、优化范围、初始化与增密策略，不能用被目标遮挡的原始像素监督删除后的背景，也不能使用清场评测 GT 训练。背景保护与局部优化作为后续独立变量，避免同时改变而影响归因。本轮不再要求用户重复操作或验收。
